仕事の概要

港町ロングショアの下っ端チンピラが主人公。スマホに届く仕事――配達、送迎、車両回収――をこなして金を稼ぎ、顔を売り、街の裏側を一段ずつ上がっていく。やらかせば警察に追われ、捕まれば罰金と武器没収。それでもハンドルを握り直して、次の着信を待つ。

  1. FEATURE 01

    章立てミッション全12本

    第1章「下っ端」から第2章「中堅」、第3章「幹部候補」へ。配達や送迎の小さな仕事から始めて、逃走や大口の回収まで、立場が上がるほど仕事は荒く、報酬は大きくなる。合間には繰り返し受けられる小口仕事もある。

  2. FEATURE 02

    街は一枚マップで最初から全開

    港湾、ダウンタウン、住宅、工業の4地区からなるロングショア全域を、最初から自由に走り回れる。ロックされた地区はない。どこへ行くかは、着信と自分の腕しだい。

  3. FEATURE 03

    GTA式の手配システム ★★★

    手配度は星3段階。パトカーに見られれば即星、それ以外は近くの歩行者がスマホで通報し、数秒のラグのあとに星が付く。誰にも見られていなければ、軽い衝突は星なしで済むこともある。追っ手の台数は星の数しだいで、視界を切れば星は1つずつ下がっていく。

  4. FEATURE 04

    走りやすい運転

    ドライブアシストと直進スナップ、強めのグリップで、まっすぐ走るのが苦手でも車が暴れない。操作は画面基準が既定で、スティックを倒した方向へそのまま進む。設定で車基準にも切り替えられる。

  5. FEATURE 05

    コントローラー対応

    運転からスマホの着信の受諾まで、パッドだけで操作できる。仕事はスマホ型のパネルに届き、十字キーとボタンで受ける。キーボードとタッチでも遊べる。

操作の要点：運転は左スティック／WASD ― 画面基準が既定（設定で車基準に切替可）。仕事はスマホの着信から受ける。進み具合はミッション完了などで自動保存。
