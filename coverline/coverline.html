【コントローラー診断】
この表示環境では、コントローラー機能がブロックされています。
診断の「取得エラー」にある通り、この画面を埋め込んでいるアプリ／ブラウザ側が Gamepad API の利用をポリシーで禁止しているため、ゲーム側からコントローラーを読み取ること自体ができません。パッド本体・USB接続・ボタン押下の問題ではありません（HORI製でも同じ結果になります）。
  • 対処法：このページを Chrome / Edge などのブラウザで通常のタブとして直接開くと、Gamepad API が許可され、コントローラーで遊べます。開いたあと、画面を一度クリックしてからパッドのボタンを押してください。
  • この埋め込み表示のままでは、キーボード／マウス（スマホ・タブレットではタッチ）で全機能を遊べます。
  • 環境を変えたら、下のボタンでもう一度検出を試せます。
コントローラーは、ゲーム画面を一度クリック（タップ）してからボタンを押すと認識します。Xbox系のほか、HORIなどの社外パッドにも対応しています（非標準マッピングの読み替え、十字キーだけのパッドでの移動、トリガーが軸で届く機種にも対応）。認識すると上の欄と左上に機種名つきで「接続中」と表示されます。未接続のままのときは上の「コントローラー診断」を見てください：いずれかのスロットに機種名（id）が出ていればブラウザには見えていて、ボタン番号や軸の値がボタン操作に反応するかで切り分けられます。全スロット「なし」の場合は、この画面を開いているブラウザ側がパッド入力を受け取れていない状態です。診断に「permissions policy」と出ている場合は、表示環境側がコントローラー機能を禁止している状態で、上の案内が対処法になります（ボタンを押しても認識しません）。カバー中は正面の弾を防げますが側面・背後からは当たります。敵もカバーを使い、タレットは囮にもなります。 スマホ・タブレットではタッチでも遊べます：画面の左半分をドラッグで移動、右半分をドラッグで照準（強く倒すと射撃）、カバーやタレットは画面のボタンから使えます。

カバー：車やバリケードの近くで Space / A を押すと吸着。吸着中は左右移動でカバー沿いに動ける。 撃つときは 右クリック / LT で身を乗り出す（その間は敵の弾も当たる）。 タレット：Q / LB。 拾う：武器の近くで E / X 長押し。今の武器との強さ比較が出る。アーマーキットは触れれば自動で拾う。 タッチ：左半分ドラッグ＝移動、右半分ドラッグ＝照準・射撃、ボタンでカバー／ロール／タレット等。 環境音：M で ON／OFF。風と街の低い残響に混じって、遠くの銃声や地響きが時々聞こえる（戦闘の気配は音だけの演出で、実際の敵とは連動しない）。 BGM：N で ON／OFF。ダークな電子パルスのループで、敵が近づいたり撃ち合いが始まるとリズムと低音が乗って戦闘版に切り替わり、静まると数秒かけて探索版へ戻る。環境音とは別々に切り替えられる。 フルスクリーン：画面右の ⛶ ボタン / Alt+Enter で切替、Esc で解除。
