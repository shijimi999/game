作戦概要

旅行で山岳地帯の小国を訪れた主人公は、独裁者「将軍」の私兵軍による支配に巻き込まれる。レジスタンスとともに拠点を解放し、鐘の塔を止めて地図を開きながら北へ進み、最後は放送本部で将軍の放送を止める。

  1. FEATURE 01

    拠点解放

    拠点9つと要塞、そして最奥の放送本部。ステルスでも正面からでも落とせる。エリア2の拠点を解放するごとに、放送本部の警備は薄くなっていく。

  2. FEATURE 02

    鐘の塔と地図

    鐘の塔は全4基。塔の放送設備を止めると将軍のプロパガンダ放送が止み、その一帯の地図が開く。解放した拠点と塔のあいだはファストトラベルで行き来できる。

  3. FEATURE 03

    武器5種＋投擲

    ピストル、アサルトライフル、ショットガン、スナイパーライフル、弓の5種。投擲は石ころ、手榴弾、火炎瓶、動物を呼ぶ肉。カメラで敵をマークしてから仕掛けることもできる。

  4. FEATURE 04

    スキルツリーとカルマ

    スキルは虎（攻撃）と象（防御）の2系統、各6種。道中では人質救出などのカルマイベントが起こり、薬草から作る注射や、将軍のポスター剥がし（全12枚）も進み具合に数えられる。

操作：コントローラー／キーボード両対応 ― 回転はスナップターンが既定で、画面シェイクや視野角の変化を抑えた、3D酔いしにくい設計です。
